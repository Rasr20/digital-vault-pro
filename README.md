## 🔒 Privacy-First Architecture

Unlike traditional web converters that upload your confidential documents, photos, or API tokens to remote cloud servers, **Digital Vault PRO processes everything locally inside your browser**:

1. **Zero File Uploads**: PDF manipulation, image resizing, format conversions, and hashing run strictly inside the browser thread.
2. **WebAssembly & Web Crypto**: Heavy operations use client-side WebAssembly (`pdf-lib`, image codecs) and hardware-accelerated `window.crypto.subtle`.
3. **Blazing Fast**: Static delivery via Cloudflare Workers Edge CDN (< 50ms TTFB worldwide).
4. **Offline Ready**: Full Progressive Web App (PWA) with Service Worker caching.

## 🛠️ Featured Tool Categories

### 💻 Developer Tools
- **cURL Converter**: Convert cURL commands into clean Fetch, Axios, Python requests, Go, or PHP code.
- **JSON to TypeScript**: Instant interface generation with nested objects and type inference.
- **Cron Expression Builder**: Human-readable schedules with next-run previews and presets.
- **JWT Debugger**: Inspect headers, claims, expiration, and payload without exposing tokens to third-party backends.
- **Chmod Calculator**: Visual permission matrix with numeric octal notation and CLI commands.
- **UUID & Hash Generator**: Cryptographically secure UUID v4/v7 and SHA-256 / SHA-512 hashes.

### 📄 PDF Utilities
- **Merge PDF**: Combine multiple PDF files in custom order.
- **Split PDF**: Extract specific page ranges into standalone documents.
- **PDF to JPG / JPG to PDF**: High-resolution page extraction and image bundling.

### 🖼️ Image & Media Tools
- **Image Compressor**: Compress JPEG/PNG/WebP to exact KB targets without quality loss.
- **HEIC to JPG**: Convert Apple HEIC photos instantly in the browser.
- **Favicon & OG Image Generator**: Responsive icon packs and social preview cards.
- **Aspect Ratio Calculator**: Scale resolutions maintaining standard 16:9, 4:3, or custom ratios.

### 📝 Text & Data
- **Diff Checker**: Side-by-side text comparison with highlighted additions and deletions.
- **CSV to SQL / Markdown Table**: Data conversion for databases and documentation.
- **Regex Tester**: Real-time pattern matching with cheat sheet.
- **HTML/CSS/JS Minifier**: Clean whitespace and comments for production code.
